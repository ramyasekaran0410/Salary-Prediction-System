# 📌 Employee Salary Prediction & Exploratory Data Analysis (EDA)

## 📖 Problem Statement

In today's corporate landscape, determining a fair and competitive compensation structure is critical for talent acquisition and employee retention. Salary levels are typically influenced by multiple factors such as professional experience, age, educational background, job role, and demographic factors.

The objective of this project is to perform an end-to-end **Exploratory Data Analysis (EDA)**, **Statistical Evaluation**, and **Predictive Modeling** on employee demographic and employment data to understand how factors like **Experience**, **Age**, and **Gender** impact an employee's **Salary**, and to build a regression model using a **Decision Tree Regressor** to predict salary outcomes.

---

## 🎯 Objectives

* **Data Ingestion & Inspection:** Load, inspect, and summarize the dataset structure (features, data types, missing values, duplicates).
* **Data Preprocessing:** Handle categorical variables via **Label Encoding** and scale numerical values using **Min-Max Scaling**.
* **Statistical Analysis:** Calculate descriptive statistics (Mean, Median, Mode, Variance, Standard Deviation) and detect outliers using the **Interquartile Range (IQR)** method.
* **Exploratory Data Analysis (EDA):** Visualize distributions, relationships, and feature correlations using histograms, scatter plots, count plots, box plots, and correlation heatmaps.
* **Predictive Modeling:** Train a **Decision Tree Regressor** using key features (`Experience`, `Age`, `Gender`) to predict the normalized salary and evaluate the model using the $R^2$ Score.

---

## 📊 Dataset Overview

The dataset contains employee attributes including:

* **Name:** Employee identifier
* **Education:** Educational qualification (High School, Bachelor, Master, PhD)
* **Experience:** Years of professional experience
* **Location:** Work location type (Urban, Suburban, Rural)
* **Job_Title:** Role (Manager, Director, Analyst, Engineer, etc.)
* **Age:** Age of the employee
* **Gender:** Employee gender (Encoded numerically)
* **Salary:** Target variable (Original & Min-Max Scaled)

---

## 🛠️ Tech Stack & Libraries

* **Language:** Python
* **Data Manipulation:** `pandas`, `numpy`
* **Data Preprocessing & ML:** `scikit-learn` (`LabelEncoder`, `MinMaxScaler`, `DecisionTreeRegressor`, `train_test_split`, `r2_score`)
* **Data Visualization:** `matplotlib`, `seaborn`

---

## 🚀 Key Workflow Steps

1. **Day 1 & 2 - Data Handling:** Loading CSV data, inspecting `.head()`, `.tail()`, `.shape`, `.dtypes`, and filtering specific roles/columns.
2. **Day 3 - Preprocessing:** Deduplication, categorical encoding on `Gender`, and normalization of `Salary` via `MinMaxScaler`.
3. **Day 4 - Descriptive Statistics & IQR:** Computing distribution metrics and verifying outlier bounds.
4. **Day 5 - EDA & Visualization:** Generating univariate and bivariate plots along with a feature correlation matrix.
5. **Machine Learning Pipeline:** Splitting data (80/20 train-test split), training the `DecisionTreeRegressor` (max depth = 5), and visualizing the decision tree structure.
